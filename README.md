## DEDXC 使用顺序

以下任务可以限定在站内 SEO / GEO 范围，不需要执行外链提交。

| 工作 | seo-skills 模块 |
| --- | --- |
| 业务档案与页面基线 | seo-profile-setup、site-inventory |
| 技术与收录检查 | technical-audit、indexation-check |
| 关键词与页面分配 | keyword-page-mapping |
| 标题与正文结构 | meta-writer、heading-architect、page-optimiser |
| 内链与结构化数据 | internal-linking、schema-builder |
| AI 可访问性与 GEO 内容 | ai-crawler-access、geo-rewrite |
| 数据复盘 | performance-report、content-decay |

marketingskills 中优先使用 seo-audit、ai-seo、site-architecture；schema、content-strategy、cro 可用于配套优化。下方提供各模块入口。
